## Design and Color Scheme

The website uses a blue, gold, black, and light neutral color scheme.

- Deep navy blue (#102A56) is used for the main brand color.
- Gold (#D4AF37) highlights navigation interactions, borders, and buttons.
- Black (#151515) provides contrast in backgrounds and text.
- White and light blue keep the content readable.

### Gradients

- The header uses a linear gradient transitioning from navy blue to black.
- The main content uses an angled 135-degree gradient transitioning through white, light blue, and a subtle gold tint.
- The body and footer use blue and black gradients.

The gradients are defined in style.css.


## Responsive Design and Viewport Sizes

The website uses separate CSS files for mobile phones, tablets, and laptops or larger screens.

- Mobile: Up to 600 pixels wide. The navigation links are displayed vertically, and the content uses smaller margins and padding to fit narrow screens.
- Tablet: 601 to 900 pixels wide. The content area and heading sizes are adjusted to make the website comfortable to view on medium-sized screens.
- Laptop and larger screens: 901 pixels wide and above. The content area uses a wider layout with additional spacing.

These breakpoints were chosen to adapt the website's layout to different screen sizes and improve readability and navigation.

The responsive styles are stored in mobile.css, tablet.css, and laptop.css. The general styles are stored in style.css.

## Testing

Before submission, the website should be checked using:

- W3C HTML Validator to check HTML errors.
- W3C CSS Validator to check CSS errors.
- W3C Link Checker to check links.
- WAVE Web Accessibility Evaluation Tool to identify accessibility issues.
- A spell checker to check spelling and grammar.

The navigation, contact form validation, photo, video, and responsive layout should also be tested manually.
